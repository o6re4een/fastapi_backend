# Онлайн-афиша API

Проект представлен в качестве API для aфиши кинотеатра (Вариант-4), который включает в себя ключевые элементы управления и реализует следующий функционал:

- Работа с фильмами
  (получение списка фильмов с возможностью фильтрации по жанру и рейтингу, пагинации; получение фильма по id; создание, редактирование и удаление фильмов)

- Работа с билетами
  (создание билета, получение билетов по пользователю, обновление билета, просмотр всех билетов для кассиров и администраторов)

- Работа с отзывами
  (создание отзыва на фильм, получение всех отзывов и отзывов по фильму, редактирование и удаление отзыва)

Также данный API поддерживает разделение пользователей на роли:

- Покупатель — просмотр фильмов, написание отзывов, покупка билетов
- Кассир — управление сеансами и билетами
- Админ — полный доступ ко всем сущностям и действиям

# Запуск проекта

1. Создайте и запустите виртуальное окружение с помощью команды
   `python -m venv venv`
   `.\venv\Scripts\activate`
1. Установите все зависимости с помощью команды
   `pip install -r requirements.txt`
1. Создайте файл .env и вставте туда следующие строки

   ```
   DB_NAME="название вашей базы данных c расширением .db"
   SECRET_KEY="ваш ключ"
   ALGORITHM="HS256"
   ```

1. Сохраните все и в терминале введите команду
   `python .\seed.py`
1. Чтобы запустить сервер введите команду
   `fastapi dev main.py`
